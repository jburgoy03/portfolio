A self-hosted audiobook library. The server indexes a directory of m4b and mp3 files, extracts chapters and cover art, and serves them over range requests so seeking works properly. Clients report playback position back to the API, which resolves conflicts when you switch devices mid-book.

Matchday

Live

A Premier League site with fixtures, live scores, lineups and the league table. A background worker syncs data from a public sports feed into Postgres on a schedule that follows the matches: it polls every minute while a game is live, watches for lineups before kickoff, and goes quiet between matchdays. The React front end reads only from its own API, so pages stay fast even when the upstream feed doesn't.

.NET 10, EF Core, PostgreSQL, React, TypeScript, Docker
