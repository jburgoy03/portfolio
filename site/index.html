Earmark

A self-hosted audiobook server and player. The server indexes m4b and mp3 files, extracts chapters and cover art, and serves them over range requests so seeking works properly. Web and Android clients sync playback position, and the API resolves conflicts when you switch devices mid-book.

Matchday

A Premier League site with fixtures, live scores, lineups and the table. A background worker polls every minute while a game is live, watches for lineups before kickoff, and goes quiet between matchdays. The front end reads only from its own API, so pages stay fast when the upstream feed doesn't.
